PowerShell

24 COMMANDS INDEXED

(new territory — the mental model that matters: everything is an object, not text, so you pipe properties, not parsed strings)

Basic

 
# prints the current working directory — pwd equivalentGet-Location
# changes the current working directory — cd equivalentSet-Location C:\path
# duplicates a file under a new name in the same folder — cp equivalentCopy-Item file.txt backup.txt
# moves (or renames, if the destination is a filename) a file — mv equivalentMove-Item file.txt archive\
# deletes a file — rm equivalent; add -Recurse for a folder and its contentsRemove-Item file.txt
# creates a new directory — mkdir equivalentNew-Item -ItemType Directory -Path newfolder
# assigns a variable for the current session, no export needed like in bash$var = "value"
# reads the PATH environment variable — the $env: prefix is how you access any env var$env:PATH
# lists the 10 processes using the most CPU right now, heaviest firstGet-Process | Sort-Object CPU -Descending | Select-Object -First 10
# filter, like grep but on real objectsGet-Service | Where-Object {$_.Status -eq 'Running'}
# recursively searches the current folder for any file over 100MBGet-ChildItem -Recurse -File | Where-Object {$_.Length -gt 100MB}
# streams a file's new lines as they're written, starting from the last 20Get-Content log.txt -Wait -Tail 20
Enhanced 
# discover cmdlets by keyword, don't memorize namesGet-Command *service*
# full docs for any cmdlet, offlineGet-Help Get-Process -Full
# inspect what properties/methods an object actually has — the PowerShell equivalent of &quot;what fields does this JSON have&quot;$_ | Get-Member
# run something on multiple remote machines at onceInvoke-Command -ComputerName host1,host2 -ScriptBlock { Get-Service }
# checks whether a specific TCP port on a host is reachableTest-NetConnection host -Port 443
Get-WinEvent -LogName System -MaxEvents 50 # modern replacement for Get-EventLog
# native JSON handling, no external toolConvertTo-Json / ConvertFrom-Json
# unwrap a single property instead of the whole objectSelect-Object -ExpandProperty Name

Coming from Python: Where-Object ≈ filter/list comprehension, ForEach-Object ≈ map, Select-Object ≈ picking dict keys, and the pipe | passes live objects, not strings — so $_.Status works exactly like accessing an attribute in Python, no parsing required.

Health check
  1. Execution policy allows the script to run — Get-ExecutionPolicy — red flag: Restricted — the script won't run at all, and the error message doesn't always make that obvious.
  2. Required modules are available — Get-Module -ListAvailable <module_name> — red flag: not found — better to know before the script fails halfway through.
  3. Remoting works, if the script needs it — Test-WSMan <host> — red flag: fails — Invoke-Command against that host will fail too, for the same underlying reason.

Troubleshooting

Script won't run — "execution of scripts is disabled":

# see the current restriction levelGet-ExecutionPolicy
# allow locally-written scripts to run, without loosening policy machine-wideSet-ExecutionPolicy RemoteSigned -Scope CurrentUser

Module not found:

# confirm it's actually installed, and whereGet-Module -ListAvailable <module_name>
# install for your user only, no admin rights neededInstall-Module <module_name> -Scope CurrentUser
